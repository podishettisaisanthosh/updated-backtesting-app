# 📊 Backtesting Page Development

A React-based Backtesting UI application designed to configure, execute, and analyze trading strategy backtests.

---

## ⚙️ Setup Instructions

Follow the steps below to run the project locally.

---

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/podishettisaisanthosh/updated-backtesting-app
cd Backtesting-Page-Development/backtest-app
```


### 2️⃣ Install Dependencies

```bash
npm install
```


### 3️⃣ Install Tailwind CSS (If Fresh Setup)

```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

Configure tailwind.config.js and add Tailwind directives in your CSS file if not already configured.


### 4️⃣ Run the Application

```bash
npm start
```

### 🚀 Application URL

After running the server, the application will be available at:

```bash
http://localhost:3000
```
